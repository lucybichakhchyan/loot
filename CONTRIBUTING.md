# Contributing to LOOT

Thank you for your interest in LOOT. I built it for my own videos, and I'm happy when other people use it, copy it and make it their own.

## Make it your own

Fork LOOT and change anything you like. The README explains how to run your own copy and set your own brand. You don't need to ask first.

## Report a bug or share an idea

Open an issue and choose "Bug report" or "Idea". For a bug, say what you did, what you expected and what happened instead. A screenshot or a short recording helps a lot.

## Send a fix

Small fixes are welcome as pull requests, such as a bug fix, a clearer sentence or a broken link. For a bigger change, open an issue first so we can agree on it before you spend time on it.

When you send a pull request:

1. Keep it to one change.
2. Say what it fixes and how you checked it.
3. Never include secrets, such as your `.env` file, API keys or passwords.

I review pull requests when I can. LOOT is a personal project, so a reply may take a few days.

## Security problems

Please don't open a public issue for a security problem. The [security policy](SECURITY.md) explains how to report one privately.

## How we treat each other

Everyone who takes part follows the [code of conduct](CODE_OF_CONDUCT.md).
