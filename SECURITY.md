# Security policy

## Report a problem privately

If you find a security problem in LOOT, please report it privately through GitHub: open the **Security** tab of this repository and click **Report a vulnerability**. Only you and I can see the report.

Please don't open a public issue for a security problem, because that shows it to everyone before it is fixed.

Tell me what the problem is, how to reproduce it, and what someone could do with it. I'll reply as soon as I can and let you know when it is fixed.

## Which versions get fixes

Only the newest version of LOOT gets security fixes. If you run your own copy, update it to the newest version on the `main` branch.

## Keeping your own copy safe

Your `.env` file holds your password and API keys. Keep it only on your server, never commit it, and use a long password.
